H-Spec (arXiv 2609.24197) injects target context into a speculative drafter by mapping the target's last-step hidden state to an SSM initial state and attending in place to the target's prefix K/V, so the drafter stores no prefix cache. Install with `pip install -e .`. Run tests with `pytest` and train with `python train.py --steps 200 --seed 0` (writes `results.json`). This toy does not match the paper: the target is a 2-layer d=32 model rather than Qwen3-8B, there is no concurrent serving and no throughput numbers, the Markov head is omitted, and Mamba-2 SSD is only the diagonal selective recurrence.
