HyperQ (arXiv 2609.24657) turns a hidden vector into per-qubit Bloch angles and per-edge couplings on a degree-4 ring-plus-chord graph, then contracts those into a classical z vector. Install with `pip install -e .`. Run tests with `pytest` and train with `python train.py --steps 200 --seed 0` (writes `results.json`: a tiny frozen-backbone masked-diffusion model with one HyperQ branch per block on the QKV projection, n=8, chord stride 3). This is not the 1.1B backbone, includes no SFT, and does not target hardware.
