JAX implementation of multi-agent cooperation-driven training from arXiv:2609.16917 (Ketcha Kouakep, UANN, Carletti).

Install: `python3 -m venv .venv && .venv/bin/pip install -U pip wheel && .venv/bin/pip install -e ".[dev]"` (on this NixOS box, export `LD_LIBRARY_PATH=/nix/store/larys5yihddj2diyab60hpdri8n11kn7-ld-library-path/share/nix-ld/lib${LD_LIBRARY_PATH:+:$LD_LIBRARY_PATH}` first).

Run: `JAX_PLATFORMS=cpu .venv/bin/python -m pytest -q` and `JAX_PLATFORMS=cpu .venv/bin/python scripts/smoke.py`.

What does not match the paper: experiments here use tiny 2D Gaussian blobs, not MNIST/Fashion-MNIST/CIFAR-10; agents are 1-hidden-layer MLPs (hidden 8 vs 32) rather than the paper's 2-MLP sizes. Paper eq. (5) sets `w_k = softmax(-H_k / τ)` (already summing to 1); `confidence()` implements `1 - H / log(C)` in [0, 1] and weighted-average / simplicial consensus normalizes those scores, with `softmax_weights(probs, tau)` for eq. (5). Eq. (11) writes a minus in front of the local CE (which would reward disagreement); training uses the positive CE of voter/majority and of eq. (14). Majority vote is one-hot argmax ballots with smallest-index tie-break; eq. (7) typesets a sum of raw softmax vectors. Combined loss is the multiplicative form of eq. (3), `L * (L + λ L^G)`, with default `λ = 1` as in Table I. `τ` defaults to 1.0 (paper only states `τ > 0`). Smoke uses SGD, not Table IV's Adam (`η = 10^{-3}`, batch 128, 20 epochs). Simplicial consensus is all-to-all confidence-weighted averaging on the simplex, not a graph 1-simplex / pairwise KL.
