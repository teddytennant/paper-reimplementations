Signed fractional hypertree width enumeration for full conjunctive queries with negation, following Algorithms 1 and 2 of Frisk and Koutris (https://arxiv.org/abs/2610.03982). Run tests with `PYTHONPATH=src python -m pytest -q` from this directory; joins and Merge are naive, so there is no claim of the O(|I|^sfhw) preprocessing bound, rho* is an exact basic-feasible-solution search precise on the tested widths {1, 1.5, 2}, sfhw searches orders only for at most 5 variables, and the k-cycle O(|I|^{3/2}) special case (Theorem 5.2) is not included.
