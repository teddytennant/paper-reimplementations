# NormPaST-Risk

NormPaST-Risk (arXiv 2609.29384; Gong, Qin, and El-Yacoubi) is a paper-air state-space network that scores Alzheimer's risk on handwriting segments. A trajectory of x, y, pressure, and velocity, a binary on-paper mask, and a task id are encoded by two dilated temporal convolutions, pooled into fixed-stride segments that keep on-paper and in-air means separate, and passed through selective diagonal state-space layers modulated by a paper-dominant embedding. A healthy-only normative head predicts the next segment token, and a task-conditioned mixture of experts scores each segment. Install from this directory with `pip install -e .` on Python 3.11 or newer (JAX, NumPy, and Optax). Run a seeded synthetic training loop with `python train.py`. Run the tests with `python -m pytest -q`.

## What this does not match

This package is not trained on DARWIN and does not claim the accuracy reported in the paper. Dropout defaults to 0 in this package so CPU runs stay deterministic; the paper uses 0.3. The segment loss is a concrete weakly supervised reading of the prose around the paper's segment objective, not a quoted equation number: for an Alzheimer's sample the term is the negative log of the maximum segment probability plus the mean binary entropy of the segment probabilities, and for a healthy sample it is the mean negative log of one minus each segment probability. The sample head pools pre-sigmoid segment logits with attention over segment states and then applies one sigmoid, which is a concrete reading of the statement that the sample prediction is produced from the segment risks. Windows use a fixed stride and separate paper and air by masked means, rather than ending a segment at every pen-state change. Normative deviation is detached on the risk-calibration path so the normative head is trained only on healthy samples.
