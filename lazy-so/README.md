lazy-so is a small JAX library for the search-free Monteiro-Svaiter acceleration, cubic proximal oracle, preconditioned accelerated gradient descent with segment search, finite segment search, and cubic-regularized Newton step from arXiv 2610.03222. Install with `pip install -e .`, run the demo with `python -m lazy_so.demo`, and run the tests with `pytest`. It does not include the lower bound or a complexity-rate experiment, the segment-search bisection is capped at 64 iterations, tests may override N and S so the nested loop stays short, and the m-lazy cost is the accounting function lazy_iteration_cost.
